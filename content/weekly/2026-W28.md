## Highlights

### Plu-stan: release plumbing, and a review cockpit

Most of the week's plu-stan work was distribution. Binaries now ship one per GHC
minor series rather than one per patch
([#56](https://github.com/input-output-hk/plu-stan/pull/56)), `.hie` files are
read across patch releases within a series
([#52](https://github.com/input-output-hk/plu-stan/pull/52)), and the release
build goes out plutus-free so the Windows and 9.12.2 legs succeed
([#46](https://github.com/input-output-hk/plu-stan/pull/46)); the deprecated
`olegtarasov/get-tag` action is gone
([#47](https://github.com/input-output-hk/plu-stan/pull/47)) and 0.3.3 went out
for the series download
([#61](https://github.com/input-output-hk/plu-stan/pull/61)). Phase 1 of a VS
Code review cockpit with a schema-v2 backend also merged
([#51](https://github.com/input-output-hk/plu-stan/pull/51)). Finding-path
resolution took a round trip — merged as
[#54](https://github.com/input-output-hk/plu-stan/pull/54), a revert opened as
[#57](https://github.com/input-output-hk/plu-stan/pull/57), and re-targeted to
main as [#58](https://github.com/input-output-hk/plu-stan/pull/58).
bogdan-manole reported duplicated anti-pattern findings and closed them the same
week ([#48](https://github.com/input-output-hk/plu-stan/issues/48),
[#50](https://github.com/input-output-hk/plu-stan/pull/50)), and added a
cross-platform installer for the native crypto libraries
([#49](https://github.com/input-output-hk/plu-stan/pull/49)).

### Blaster: a benchmarking harness, built in a week

Fifteen merges went into Blaster-benchmarking: new suites — MiniF2F

([#10](https://github.com/input-output-hk/Blaster-benchmarking/pull/10)); Verina,
108 tasks ([#12](https://github.com/input-output-hk/Blaster-benchmarking/pull/12));

opened ([#140](https://github.com/input-output-hk/Lean-blaster/pull/140),
[#145](https://github.com/input-output-hk/Lean-blaster/pull/145)) alongside a
